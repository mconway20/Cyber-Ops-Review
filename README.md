# Class Portal & Resource Hub

A lightweight, static course portal built for teachers to easily organize and host unit slides, video lessons, review games (Gimkit/Wayground), and teaching guides.

## Features
* **Unit & Chapter Organization:** Collapsible chapter dropdowns for clean navigation.
* **Easy Updates:** All links and chapters are managed through a single `data.json` file, meaning no complex HTML editing required.

---

## Project Structure
```text
/
├── index.html      # Main layout template
├── style.css       # Modern styling & responsive design
├── script.js       # Dynamic JSON loader and UI generator
└── data.json       # Course content, units, chapters, and links
```
